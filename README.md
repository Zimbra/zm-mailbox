# Agent Memories

This branch stores analysis, coverage snapshots, and learnings
generated by the JUnit Agent Pipeline. It has NO source code.

## Structure

| Directory    | Contents                                         |
|-------------|--------------------------------------------------|
| `analysis/` | Per-package code analysis markdown files         |
| `coverage/` | JaCoCo coverage snapshots (JSON)                 |
| `learnings/`| What worked / what failed per pipeline run       |

## Notes
- Do NOT merge this branch into develop/main
- Managed automatically by the pipeline
- View with: git show agent-memories:analysis/<file>.md
